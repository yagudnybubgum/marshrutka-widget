# Route 605 — Design

## Goal
Add marshrutka **605** (Павлово / ул. Быкова ↔ ТЦ «Мега Дыбенко») as a first-class route tab with nearest departures and full schedule. No map geo.

## Approach
Same pattern as **664**: daily two-column XLSX (no будни/выходные), register in `ROUTES`, exclude from «С Ладожской».

## Config
```js
{ id: '605', name: '605', destination: 'ул. Быкова (Павлово)', color: 'gray' }
```
- `ROUTES_FROM_LADOZHSKAYA`: exclude `605` (like `664`)
- `LEGACY_FULL_ROUTES`: add `'605'`
- Direction copy: `fromPavlovo: 'Из Павлово, ул. Быкова'`; Mega already maps via existing `fromMega`
- `formatDirectionName`: match Павлово / Быкова → `fromPavlovo`
- Column order in XLSX: Павлово first, МЕГА second (matches operator sheet)
