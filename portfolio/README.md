# Marshrutka: Home Anatomy (portfolio export)

Автономная зацикленная anatomy-анимация главного экрана.

## Файлы

```
portfolio/
  marshrutka-home-anatomy.html   ← открыть в браузере
  gsap.min.js                    ← локальный GSAP (без CDN)
```

Оба файла должны лежать **в одной папке**.

## Запуск

```bash
open portfolio/marshrutka-home-anatomy.html
```

или просто двойной клик по HTML. Сеть не нужна.

## Встроить в портфолио

- iframe на эту страницу, или
- скопировать оба файла в статику сайта и линкануть `/marshrutka-home-anatomy.html`
